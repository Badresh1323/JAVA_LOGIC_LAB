 
# Java Logic Lab ☕

A collection of small Java programs I'm building while learning programming fundamentals.

## 🎯 Goal

Learn Java through small practical projects instead of only watching tutorials.

## 📂 Projects

### 1. Calculator

A simple command-line calculator that supports:

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

## 🧠 Concepts Practiced

- Variables
- Data types
- Scanner
- User input
- Operators
- If-else statements
- Basic validation

## 🚀 Learning Approach

Build → Break → Debug → Understand → Repeat
